# Пространства

Лёгкий менеджер изолированных браузерных профилей для Windows. Каждая карточка запускает Chromium-браузер с отдельным каталогом данных: cookie, local storage, история, разрешения и входы не смешиваются между пространствами.

## Что уже работает

- создание и изменение пространств;
- отдельный каталог браузерных данных для каждого профиля;
- стартовая страница профиля (по умолчанию `https://ya.ru/`);
- отдельный язык запуска Brave для профиля;
- размер окна: развёрнутый, ноутбук, Full HD, планшет или компактный;
- дата и время создания профиля;
- настраиваемый для каждого профиля таймер готовности в днях и часах;
- статус `READY` и цветная обводка готового профиля по его назначению;
- назначение профиля: ресторан, магазин или оба;
- регион из фиксированного списка с видимым UTC-offset;
- фильтр по ресторану, магазину и профилям с обоими назначениями;
- отображение текущего публичного IPv4 и ручная повторная проверка со статусом изменения;
- сохранение на карточке последнего публичного IPv4, зафиксированного при запуске профиля;
- автоматический поиск Brave, затем Edge и Chrome;
- автоматическая загрузка и установка Brave с официального HTTPS-адреса после проверки цифровой подписи;
- выбор установленного или portable-браузера вручную;
- архивирование профилей;
- удаление каталога данных через Корзину.

Brave используется как предпочтительный браузер благодаря встроенной защите от fingerprinting. Если Brave не установлен, приложение может работать с Edge или Chrome в резервном режиме, сохраняя изоляцию локальных данных без усиленной privacy-защиты.

Выбранный регион автоматически задаёт IANA timezone профиля. При запуске приложение создаёт случайный локальный DevTools-порт, доступный только через `127.0.0.1`, и отдельный скрытый helper применяет timezone к вкладкам. Начальная страница открывается после установки timezone; новые вкладки получают настройку через auto-attach. Helper завершается вместе с браузерным DevTools-соединением.

Публичный IPv4 проверяется при запуске, по кнопке обновления и после открытия профиля через `api.ipify.org`. Текущий результат в шапке хранится в памяти до закрытия приложения. IP, зафиксированный при последнем запуске конкретного профиля, сохраняется в его локальной карточке.

## Обновления на ноутбуке

Один раз скачайте новый `Spaces.exe` из Releases и замените старый EXE при закрытом приложении и окнах пространств. Версии начиная с 1.1.0 проверяют GitHub при запуске и показывают кнопку «Обновить до …». Установка выполняется по нажатию, с перезапуском приложения.

Обновлятор проверяет источник, размер, SHA-256 из GitHub и версию EXE. Он заменяет только программу. Настройки, список пространств и браузерные данные находятся отдельно в `%LOCALAPPDATA%\SpacesBrowser`. Перед заменой создаётся копия `profiles.json`, `settings.json` и прежнего EXE в подпапке `Backups`. Cookie и другие файлы `BrowserData` не изменяются. Это резервная копия настроек и списка, а не всей истории браузеров. При необходимости старый EXE можно взять из этой копии. Если Windows блокирует замену, старый файл остаётся на месте.

Приложение не загружает локальные профили в GitHub. Токен GitHub на ноутбуке не нужен: репозиторий публичный. Проверка целостности доверяет вашему GitHub-репозиторию и HTTPS; цифровой подписи издателя у Spaces.exe пока нет.

## Публикация новых версий

1. Изменить код и увеличить `Version` в `SpacesBrowser/SpacesBrowser.csproj` (например, `1.1.1`).
2. Сохранить изменения в ветке `main`.
3. GitHub Actions проверит сохранность данных, соберёт автономный EXE для Windows x64 и создаст Release. Уже опубликованная версия не перезаписывается.

Для локальной проверки обновлятора без установленного Brave:

```powershell
dotnet run --project SpacesBrowser.SmokeTests -c Release -- --updates-only
```

## Запуск из исходников

```powershell
dotnet run --project .\SpacesBrowser\SpacesBrowser.csproj
```

Переносимая сборка находится в `portable-win-x64\Spaces.exe`. Это один автономный файл со встроенным .NET Desktop Runtime: его можно скопировать на другой компьютер с Windows 10/11 x64 и запустить без установки дополнительных компонентов. Если Brave отсутствует, кнопка в приложении скачает официальный установщик, проверит подпись издателя, установит браузер и найдёт его автоматически. Для этого шага нужен интернет; Windows может показать стандартное системное подтверждение запуска установщика.

## Проверка

```powershell
dotnet build .\SpacesBrowser\SpacesBrowser.csproj
dotnet run --project .\SpacesBrowser.SmokeTests\SpacesBrowser.SmokeTests.csproj
```

Пользовательские данные сохраняются в `%LOCALAPPDATA%\SpacesBrowser`. Приложение не меняет IP, геолокацию или поведение пользователя и не обещает, что сторонние сервисы будут считать пространства разными физическими устройствами.
